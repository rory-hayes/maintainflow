# Synthetic bank-statement fixtures

Every account, identifier, transaction and amount in this directory is invented for testing. None represents a customer or establishes support for a particular bank.

- `euro-current-account.json`: day-first dates, German decimal punctuation, debit/credit markers and a current-account balance.
- `usd-large-values.json`: US formatting and amounts beyond JavaScript's safe integer precision.
- `debit-increases-card.json`: a card statement where debits increase the amount owed.
- `generated/synthetic-native-multipage.pdf`: a real two-page PDF with a repeated table header and a wrapped description.
- `generated/synthetic-scanned-multipage.pdf`: the same invented statement as an image-only PDF.
- `generated/synthetic-scanned-page.png`: page one only; missing page-two totals must remain absent.

The source fixtures are generated by `scripts/bank-statement-fixtures.ts`. Its controlled provider responses are supplied by test transports and are **not** measured OCR or extraction accuracy. Tests separately verify original bytes, page counts, provider request contents, normalization, review checks, approvals and exported rows.
