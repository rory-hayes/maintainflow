Controlled tests cover recursive structures; actual browser table disclosures, keyboard operation and desktop/mobile page navigation passed after a targeted CSS overflow fix.

## Source association

[ExtractionSources.tsx](../src/features/documents/ExtractionSources.tsx) reads only the selected run's schema, immutable `rawValues` and evidence map. It follows full paths such as `groups[0].items[1].amount`, shows original row numbers, distinguishes table/object quotes from leaf quotes, and retains all recorded quotations. Absent original values stay absent; defaults and corrected values are not substituted into this source record. Empty arrays, zero and false remain distinct.

Corrections do not record row lineage. Attaching quotes to the current editable row index would therefore misattribute evidence after a row is removed, added or reordered. The separate original-source disclosure keeps its original rows and quotations unchanged while the current values remain editable above it. Its explanation states that corrections do not change the source record.

Native and AI-read quotations retain their existing labels. The global warning still asks reviewers to compare model-visual quotes with the original. React escapes labels, values and quotes as text; no source HTML is executed. Complete quotes wrap, and source buttons use the existing page callback in [Review.tsx](../src/features/documents/Review.tsx), which also selects the Document tab at mobile width. Controlled callback tests are separate from browser click/focus proof.
