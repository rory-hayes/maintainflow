# Security policy

## Supported version

MaintainFlow Ads is in private development. Security fixes are made on the
current `main` branch; older commits and the paused legacy Maintain Flow
deployments are not supported releases of this product.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting channel:

https://github.com/rory-hayes/maintainflow/security/advisories/new

Do not open a public issue for a suspected vulnerability. Include the affected
route or component, prerequisites, impact, and the smallest safe reproduction
you can provide. Do not include customer credentials, API keys, raw conversion
events, personal data, or data taken from a real advertiser account.

## Safe research boundary

Only test systems and accounts you own or have explicit permission to test.
Do not test the paused legacy Maintain Flow deployments, OpenAI infrastructure,
customer storefronts, or third-party services on MaintainFlow's behalf. A
private report does not itself grant testing authorization.
